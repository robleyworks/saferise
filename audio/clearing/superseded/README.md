# Superseded Clearing material

`clearing-noun-forms-2026-09-13.txt` was the Clearing script until 18 September 2026.
It is superseded by `../clearing.txt` (the verb-close version).

Why it was retired:
- It uses the retired noun forms — "Recognition. Regulation. Release. Rise." The canonical
  step names are the verbs: Recognise · Regulate · Release · Rise.
- It opens "There's an engagement ahead of you…", framing the session around a specific
  upcoming event. The live version frames it as a doorway into any protocol.

The three renders in the parent folder — `Clearing_t0-00.mp3`, `Clearing_v2.mp3`,
`Clearing_SRF.mp3` — were all built from this superseded text and carry the noun forms.
They are not the live audio. The live Clearing vocal was recorded in ElevenLabs Studio on
18 September 2026 and is not yet in this repo.
