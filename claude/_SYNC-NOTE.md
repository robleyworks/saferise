# Why some documents are here and most are not

30 September 2026, SR-491.

The SafeRise project holds around 230 working documents. This directory holds
only the ones a pass brief actually cites, because the coding session reads the
repository, not the project. A brief that names a document not present here
cannot be followed, and the correct response is to report it rather than guess —
which is what happened to the seat-sheet prices in SR-487.

If a brief names a document that is not in this directory, say so and stop on
that item. Do not infer the figures.

Nothing in this directory is served: `/claude/*` returns 404 (see `_redirects`,
SR-491) and it is disallowed in `robots.txt`.
